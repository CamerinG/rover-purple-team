# Rover - Purple Team

### About the program
This program is an educational project for me. I'm very interested in cyberphysical security
and as I was going through some of the 'theconstruct.ai' courses I started thinking about security for the rovers. My goal with this project is to have two VM's one attacker 'red team' and one victim 'blue team'. The attacking vm will simulate a bad actor getting access to a rover subscriber/publisher system, and it will show how the events can be spoofed. I'm also going to explore some HMAC type security on the victim side, for proof of concept to show how to ensure that the subscriber is receiving the correct information from the publisher.
